##### Operators
An *operator* is a symbol that represents a form of data transformation. *Every* operator may be [specialized](Procedures.md#Operators).

###### Data Operators
A *data operator* acts *only* on the data of its operands, and yields [unbound](Data.md#Bound%20and%20Unbound%20Data) data.

- `!`, `not`
	- Logical NOT
		- `!expr`
		- `not expr`
- `?`
	- Null test
		- `target?`
- `-`
	- Unary negation
		- `-23`
	- Subtraction
		- `a - b`
- `+`
	- Addition
		- `a + b`
- `/`
	- Division
		- `a / b`
- `*`
	- Multiplication
		- `a * b`
- `%`
	- Remainder
		- `z = 5 % 3`
- `==`
	- Equality Comparison
		- `a == b`
- `!=`
	- Non-Equality Comparison
		- `a != b`
- `>=`
	- Greater-than-or-equal-to Comparison
		- `a >= b`
- `<=`
	- Lesser-than-or-equal-to Comparison
		- `a <= b`
- `>`
	- Greater-than Comparison
		- `a > b`
- `<`
	- Lesser-than Comparison
		- `a < b`
- `()`
	- Invocation/Call
		- `foo(a, b)`
- `T()`
	- [Conversion](Types.md#Conversions) to type `T`
		- `f64(x)`
- `..`
	- Exclusive range
		- `5..12`
- `~`
	- Inclusive range
		- `2~5`
- `<..`
	- Exclusive reverse range
		- `5<..12`
- `<~`
	- Inclusive reverse range
		- `2<~5`

###### Binding Operators
A *binding operator* acts on the binding of its operand: it initializes, writes, moves or destroys that binding's data, or yields [bound](Data.md#Bound%20and%20Unbound%20Data) data.

- `=`
	- Assignment
		- `x = y`
- `-=`
	- Subtract-and-assign
		- `a -= b`
- `+=`
	- Add-and-assign
		- `a += b`
- `/=`
	- Divide-and-assign
		- `a /= b`
- `*=`
	- Multiply-and-assign
		- `a *= b`
- `%=`
	- Remainder-and-assign
		- `z %= y`
- `*`
	- Dereference
		- `*p`
- `[]`
	- Indexing
		- `a[22]`
- `{}`
	- Construction
		- `Foo {.a = 102}`
- `#`
	- Copy-initialization
		- `data x = #y`
		- Is never elided
		- Invoked by the language, e.g. `data x = y`
- `$`
	- Explicit move
		- `data x = $y`
- `!{}`
	- Destruction
		- Invoked by the language, when data reaches the end of its lifetime

##### Punctuators
A punctuator is the inverse of an operator; a symbol where specialization would serve no purpose. Therefore, *no* punctuators may be specialized.

> [!note]
> The list below has some symbol overlap with the Operators list. This is because some symbols are operators in certain contexts, and punctuators in others. Only the specializable forms of these symbols are operators.


- `:`
	- Annotation
		- `x: i32`
- `=>` 
	- Target
		- `Thing => Stuff()`
- `|`
	- Multi-match
		- `Thing | Thung => Stuff()` 
- `->`  
	- Return type
		- `fn() -> i32`
	- Member access through a dereference
		- `box->address`
	- Indexing through a dereference
		- `scores_ptr_ptr->[2]`
	- Invocation through a dereference
		- `double_ptr->(4)`
- `{}` 
	- Scope
		- `{ data x = 23 }`
- `[]` 
	- List-expression
		- `[a, b, c]`
	- List-type annotation
		- `[i32]`
		- `[i32, f32]`
		- `[i32, 8]`
- `*`
	- Pointer-type annotation
		- `*i32`
		- `mut *i32`
- `?`
	- Nullable pointer-type annotation
		- `?*i32`
		- `mut ?*i32`
- `()`
	- Parameter List
		- `fn (a: i32, b: bool)`
	- Parenthesized Expression (Grouping)
		- `(a + b) / c`
- `"` 
	- String Literal
		- `"Hey"`
- `'`
	- Character Literal
		- `'\n'`
- `.` 
	-  Member access
		- `a.foo(c.bar)`
- `::` 
	- Scope resolution
		- `import Foo::Bar`
- `;` 
	- Statement terminator
		- `data x = 5;`
- `||`, `or`
	- Short-circuiting logical OR
		- `a || b`
- `&&`, `and`
	- Short-circuiting logical AND
		- `a && b`
- `&` 
	- Address-of
		- `data x = &y`
- `@`
	- Attribute
		- `@[Inline]`
